### Задание 2. Создание класса OnSwipeTouchListener
Разработан универсальный обработчик жестов, реализующий View.OnTouchListener. Внутри используется GestureDetector с переопределёнными методами:

onFling – распознаёт свайпы в четырёх направлениях (порог дистанции 100 px, скорость 100 px/s).

onLongPress – долгое нажатие.

onDoubleTap – двойное касание.

Класс имеет пустые публичные методы (onSwipeRight(), onSwipeLeft(), onSwipeTop(), onSwipeBottom(), onLongPress(), onDoubleTap()), которые переопределяются при использовании. Это позволяет легко назначать действия на жесты для любого View.`
```java
if (Math.abs(diffX) > Math.abs(diffY)) {
    if (Math.abs(diffX) > SWIPE_THRESHOLD && Math.abs(velocityX) > SWIPE_VELOCITY_THRESHOLD) {
        if (diffX > 0) onSwipeRight(); else onSwipeLeft();
    }
}
```

### Задание 3. Применение обработчика жестов
В GameActivity на объект gameObject установлен экземпляр OnSwipeTouchListener с анонимной реализацией всех методов:

Свайпы перемещают квадрат на 100 px в соответствующем направлении.

Долгое нажатие меняет цвет квадрата на случайный (имитация установки флажка в «Сапёре»).

Двойной тап возвращает квадрат в центр экрана.

Добавлена визуальная обратная связь – при свайпе квадрат на 150 мс становится полупрозрачным.

Таким образом продемонстрирована интеграция жестов в игровой процесс, соответствующая индивидуальному варианту «Сапёр».

Пример кода обработчиков:
```java
gameObject.setOnTouchListener(new OnSwipeTouchListener(this) {
    @Override
    public void onSwipeRight() { moveObject(100, 0); provideFeedback(); }
    @Override
    public void onLongPress() { /* смена цвета */ }
    @Override
    public void onDoubleTap() { /* возврат в центр */ }
});
```

### Задание 4. Тестирование и настройка чувствительности
Приложение запущено и протестировано. Жесты распознаются уверенно, квадрат двигается без задержек. Экспериментально подобраны пороговые значения SWIPE_THRESHOLD = 100 и SWIPE_VELOCITY_THRESHOLD = 100, обеспечивающие комфортную работу. При необходимости их можно изменить для повышения или понижения чувствительности. Дополнительно проверена корректная работа всех жестов совместно с кнопкой «Завершить игру» – конфликтов нет.
